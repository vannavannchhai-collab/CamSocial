**ប្រព័ន្ធគ្រប់គ្រងបៀវត្សរ៍ពេញលេញ ស្របតាមច្បាប់ការងារ និងប្រកាសសារពើពន្ធនៃព្រះរាជាណាចក្រកម្ពុជា**

## ✦ ចំណុចសំខាន់ — PDF តាមទម្រង់ស្តង់ដារ

ការនាំចេញ PDF គឺជាមុខងារស្នូលរបស់ប្រព័ន្ធ។ រាល់ទម្រង់ត្រូវបានរៀបចំជា **ទំព័រ A4 ពិតប្រាកដ**
(២១០×២៩៧ ម.ម បញ្ឈរ · ២៩៧×២១០ ម.ម ផ្ដេក) ហើយនាំចេញជា **១ ទំព័រ PDF = ១ ទំព័រ A4**។

| លក្ខណៈ | ការអនុវត្ត |
|--------|-----------|
| អក្សរខ្មែរ | Kantumruy Pro + Noto Sans Khmer (ផ្ទុកក្នុងម៉ាស៊ីន មិនពឹងលើ Google Fonts) |
| ការបង្ហាញអក្សរ | រៀបចំជា HTML/CSS ពិតប្រាកដ → រៀបអក្សរខ្មែរត្រឹមត្រូវ ១០០% (coeng, ព្យញ្ជនៈជើង, ស្រៈ) |
| ទំហំទំព័រ | A4 ពិតប្រាកដ · គែម ១២ ម.ម · ស៊ុមពីរជាន់តាមទម្រង់ផ្លូវការ |
| ការកាត់ទំព័រ | កំណត់ដោយដៃ — ជួរតារាងមិនដែលដាច់ពាក់កណ្តាល |
| គុណភាព | ចាប់យក ២៨៨ DPI (scale ៣) — អានបានពេលពង្រីក |
| ជម្រើសទី២ | ប៊ូតុង «បោះពុម្ព» → PDF vector តាមកម្មវិធីរុករក |

> **ហេតុអ្វីមិនប្រើ pdf-lib / jsPDF ដើម្បីសរសេរអក្សរខ្មែរដោយផ្ទាល់?**
> បណ្ណាល័យសរសេរ PDF ផ្នែក client មិនមានម៉ាស៊ីនរៀបអក្សរ (text shaper) សម្រាប់អក្សរខ្មែរទេ។
> ព្យញ្ជនៈជើង (subscript consonants) និងស្រៈរួមនឹងបង្ហាញខូច ឬខ្ទេចខ្ទី។
> ដូច្នេះយើងរៀបចំទំព័រជា HTML ពិតប្រាកដ (កម្មវិធីរុករករៀបអក្សរខ្មែរបានល្អឥតខ្ចោះ)
> ហើយចាប់យកជារូបភាពគុណភាពខ្ពស់ទៅដាក់លើទំព័រ A4 — លទ្ធផលដូចគ្នាទាំងអស់លើគ្រប់ឧបករណ៍។

## ✦ អត្រាច្បាប់ដែលបានអនុវត្ត (ឆ្នាំ ២០២៦)

### បេឡាជាតិសន្តិសុខសង្គម (ប.ស.ស)

| គម្រោង | បុគ្គលិក | និយោជក | មូលដ្ឋាន |
|--------|---------|---------|----------|
| ហានិភ័យការងារ | ០% | ០.៨% | គ្មានកម្រៃ |
| សុខាភិបាល | ១.៣% | ១.៣% | ៛១,២០០,០០០ |
| ប៉ង់ស្យ៊ុង | ២% | ២% | ៛១,២០០,០០០ |
| **សរុប** | **៣.៣%** | **៤.១%** | អប្បបរមា ៛២០០,០០០ |

ដំណាក់កាលទី១ (តុលា ២០២២ – កញ្ញា ២០២៧): ប៉ង់ស្យ៊ុង ៤% សរុប → ដំណាក់កាលទី២ (២០២៧+): ៨% សរុប។

### ពន្ធលើបៀវត្សរ៍ (ToS) — អ្នកស្នាក់នៅ

| ប្រាក់ចំណូលជាប់ពន្ធប្រចាំខែ | អត្រា | ពន្ធសន្មត |
|------------------------------|-------|-----------|
| ០ – ១,៣០០,០០០ ៛ | ០% | ០ |
| ១,៣០០,០០១ – ២,០០០,០០០ ៛ | ៥% | ០ |
| ២,០០០,០០១ – ៨,៥០០,០០០ ៛ | ១០% | ៣៥,០០០ |
| ៨,៥០០,០០១ – ១២,៥០០,០០០ ៛ | ១៥% | ៦៨៥,០០០ |
| លើស ១២,៥០០,០០០ ៛ | ២០% | ១,២៨៥,០០០ |

- កាត់បន្ថយផ្ទាល់ខ្លួន: **៛១៥០,០០០/ខែ**
- កាត់បន្ថយក្នុងបន្ទុក: **៛១៥០,០០០/នាក់/ខែ** (គូស្វាមី/ភរិយា + កូនក្រោម ១៤ ឆ្នាំ)
- ភាគទាន ប.ស.ស របស់បុគ្គលិកត្រូវកាត់ចេញមុនគិតពន្ធ
- អ្នកមិនស្នាក់នៅ: **២០% ថេរ** គ្មានកាត់បន្ថយ

### ថែមម៉ោង (ប្រកាស ២៣៣)

| ប្រភេទថ្ងៃ | មេគុណ |
|-----------|--------|
| ថ្ងៃធ្វើការធម្មតា | ១.៥× |
| ថ្ងៃសម្រាកប្រចាំសប្តាហ៍ | ២.០× |
| ថ្ងៃបុណ្យជាតិ | ៣.០× |

មូលដ្ឋានគណនា: **២៦ ថ្ងៃ/ខែ × ៨ ម៉ោង/ថ្ងៃ**

```sql
CREATE TABLE employees (id uuid PRIMARY KEY, code text UNIQUE, base_salary numeric, ...);
CREATE TABLE payroll_runs (id uuid PRIMARY KEY, period_year int, period_month int, status text, ...);
CREATE TABLE payslips (id uuid PRIMARY KEY, run_id uuid REFERENCES payroll_runs, employee_id uuid REFERENCES employees, ...);
CREATE TABLE payslip_lines (id uuid PRIMARY KEY, payslip_id uuid, kind text, code text, amount numeric);
```

គ្រប់មុខងារគណនាស្ថិតក្នុង `lib/payroll/*` ដែលជា pure functions — អាចផ្លាស់ទៅ API route ឬ
